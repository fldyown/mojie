## 使用教程

### 在 Clash Verge 中配置订阅

1. 打开 Clash Verge → 订阅管理
2. 点击「添加」→ 粘贴魔戒机场订阅链接
3. 点击「导入」→ 等待节点列表刷新
4. 切换到「代理」页面 → 选择一个节点
5. 开启系统代理即可上网

### 节点切换技巧

- **手动选择**：逐节点测试延迟，选择最快的
- **自动选择**：让 Clash 自动根据延迟选择最佳节点
- **按地区选择**：上 YouTube 选日本节点，上 ChatGPT 选香港/美国节点
- **按需求选择**：游戏用香港节点，流媒体用日本节点，AI 用香港/美国节点

### 在路由器上使用

魔戒机场支持在 OpenWrt 路由器上配置，全家设备共享一个订阅：

1. 安装 OpenClash 插件
2. 复制魔戒机场订阅链接
3. 粘贴到 OpenClash 配置页面
4. 选择节点并启用
